# KeyTrace

[简体中文](README.md) | [繁體中文](README.zh-Hant.md) | [English](README.en.md) | **日本語** | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md)

macOS のキーボード・マウス操作をローカルに記録し、3D ヒートマップ付きのアニメーション動画を書き出すツールです。

[xuhk/XAssistant](https://github.com/xuhk/XAssistant) の機能とアイデアをもとに、Swift でネイティブに再実装しました。非公式の macOS 版であり、元の作者との提携関係はありません。上流の Windows ソースコードや素材はコピーしていません。[MIT ライセンス](LICENSE)で公開しています。

「動画の説明テキストを表示」をオフにすると、タイトル・日時・説明だけを隠し、キーの文字と回数は残せます。最後の押下は重く沈んでゆっくり戻り、指定の動画時間は変わりません。メニューバーから統計を開くと、現在のデスクトップとポインタのある画面に表示されます。

## 機能

- メニューバーからバックグラウンドで操作を記録し、日別の統計とキーボードヒートマップを表示。
- 内蔵・外付けキーボードを検出。MacBook とテンキー付き Mac キーボードの配列を用意し、手動選択にも対応。
- 開始・終了日時を選択。「最初」「現在」のショートカットを使用可能。
- キーの押下アニメーションと累積ヒートマップを 1080p・30 fps の MP4 に書き出し、「ダウンロード」に保存。操作のない時間を自動で短縮。
- マウスを含めるか選択でき、速度は 0.5×〜1024×（128× / 256× / 512×を含む）に対応。
- 色の上限を再生時点の最大累積回数に追従させるか、選択期間の最終最大回数に固定。
- 最後のヒートマップを 5 秒間表示しながら、カメラをゆっくり回転。
- 各物理キーに異なる音色を割り当て、押下に同期して再生。キーボード、メカニカル、ソフト、無音から選択可能。

## インストール

正式リリース **v1.0.0**、アプリ **1.0.0 / build 16**。**Apple Silicon (arm64)、macOS 13 以降**が必要です。Intel は非対応です。**アドホック署名・Apple の公証なし。更新後に再許可が必要になる場合があります。**

[正式リリースページ](https://github.com/nope-gao/KeyTrace/releases/tag/v1.0.0) から [アプリ ZIP](https://github.com/nope-gao/KeyTrace/releases/download/v1.0.0/KeyTrace-arm64.zip) と [SHA256SUMS](https://github.com/nope-gao/KeyTrace/releases/download/v1.0.0/SHA256SUMS) をダウンロードし、下のコマンドで検証してください。自動生成の Source code ZIP はアプリではありません。展開して **KeyTrace.app** を `~/Applications` に移してから開きます。

```bash
# In the folder containing the downloaded ZIP and SHA256SUMS
awk '$2 == "KeyTrace-arm64.zip"' SHA256SUMS | shasum -a 256 -c -
```

このリリース を明示的に選ぶターミナルインストール（`/latest` は使いません）：

```bash
curl -fsSL https://raw.githubusercontent.com/nope-gao/KeyTrace/v1.0.0/install.sh -o /tmp/keytrace-install.sh
bash /tmp/keytrace-install.sh --version v1.0.0
```

インストーラは SHA-256、バージョン、署名を確認し、sudo は不要です。起動中なら停止し、同じパッケージは変更しません。署名が不一致なら置換前に停止します。移行する場合は終了して旧アプリをバックアップし、手動置換と再許可を行います。記録は保持されます。

macOS が初回起動を遮断した場合、入手元を確認して「システム設定 → プライバシーとセキュリティ → このまま開く」でこのアプリだけを許可します。Gatekeeper、SIP、システム全体の保護を無効にしないでください。管理ポリシーで例外が禁止されている場合は中止してください。

「プライバシーとセキュリティ → 入力監視」に実際のインストール先のアプリを追加し、許可後に終了・再起動します。一時停止中なら再開します。キー入力とマウスクリックで最新記録時刻とカウンタが増えることを確認してください。スイッチだけでは確認できません。更新後に動かない場合は終了し、旧項目を削除して新アプリを追加します。必要なら下のアプリ限定リセットを実行し、再許可します。

```bash
tccutil reset ListenEvent app.keytrace.mac
```

KeyTrace は独立したデータフォルダを使用し、他のアプリの記録を自動で取り込みません。初回インストール時に入力監視を許可してください。

## 固定時間

「固定時間」で動画の合計秒数を指定できます。初期値は **60秒（1分）**で、最後の**5秒のカメラ回転**を含みます。空白時間を除いた操作を自動で加速・減速します。6〜86400秒に対応します。

## 表示言語

初期設定は「システムに従う」です。macOS の優先言語リストを順に確認し、対応する言語を選びます。対応言語は **简体中文、繁體中文、English、日本語、Español、Français、Deutsch**。一致する言語がなければ英語を使用します。ウィンドウ下部で手動選択や「システムに従う」への復帰ができ、設定は保存されます。

画面、メニュー、表示済みの状態メッセージ、日時・数値、マウスのラベル、機能キー名、動画字幕に選択言語を適用します。英字キーは物理 ANSI 配列のままです。動画には書き出し開始時の言語を使い、書き出し中の手動切り替えは無効になります。OS の権限ダイアログやシステムエラーの詳細は macOS が言語を管理します。

## 動画の音

「キーボード」（既定）、「メカニカル」、「ソフト」、「無音」を選択できます。各物理キーには固有の短い音色があり、押した瞬間だけ、押下を表示する最初のフレームに合わせて再生します。高速再生で密集した操作音は重ねてミックスします。マウスを除外するとクリック音も除外され、最後の押下は低めの音になり、短い余韻が 5 秒の回転エンディングの冒頭まで続く場合があります。

音はローカルで合成します。マイクや実際のキーボード録音、外部音素材は使いません。有音の動画には 48 kHz AAC トラックを含め、無音では音声トラックを生成しません。

## ソースからビルド

```bash
xcode-select --install
bash build.sh
```

ローカルビルドはアドホック署名を使用するため、アプリの置き換え後に再許可が必要になる場合があります。

## 使用方法

期間、速度、マウスの有無、ヒートマップの方式、音を選び、「ダウンロードに書き出す」をクリックします。記録が存在しない期間の操作は復元できません。

## ローカルデータとプライバシー

データは `~/Library/Application Support/KeyTrace/` に保存します。アプリによるアップロードやテレメトリーはありません。インストーラーはリリースを取得するため GitHub に接続します。

アニメーション再生のため、押下・解放時刻、物理キー識別子、デバイス情報、イベント順序を保存します。アプリ名、Bundle ID、使用時間も記録します。入力メソッドの確定文字列、ウィンドウタイトル、URL、マウス座標は読み取りません。**キーとその順序から入力内容を推測できる場合があります。記録は機密データとして扱い、データディレクトリを公開しないでください。**

一時停止は新しい入力と使用時間の記録を止めますが、履歴は残ります。データはローカルの平文で、自動削除はありません。アプリ終了後、不要なデータ、書き出しキャッシュ、動画をゴミ箱へ移動できます。

`~/Library/Application Support/KeyTrace/` · `~/Library/Caches/KeyTrace/VideoJobs/` · `~/Downloads/KeyTrace-*.mp4`

## 既知の制限

- 主に ANSI 配列に対応。ISO/JIS は未完全対応で、すべての他社製デバイスを自動検出できるとは限りません。
- Fn、メディアキー、セキュア入力中の操作は完全に記録できない場合があります。Touch ID は通常のキー押下として記録しません。
- 複数キーボードの同時使用では入力元の識別に制限があります。長押しの自動リピートは独立した押下として数えません。
- SceneKit、Metal、AVFoundation で動画を直接生成します。Blender は不要です。
